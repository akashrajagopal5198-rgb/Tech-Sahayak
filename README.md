# Tech Sahayak

**AI-powered, voice-friendly technology assistance for everyday digital problems.**

## About the Project

Tech Sahayak is an AI-based assistance app designed to help elderly people and other users who may find technology difficult or confusing.

The app provides simple, step-by-step guidance for common digital problems instead of requiring users to understand complicated technical instructions.

## Problem

Many people struggle with everyday technology tasks such as:

* Connecting Bluetooth devices
* Troubleshooting internet or connectivity problems
* Understanding unfamiliar phone features
* Identifying possible online scams
* Following complicated technical instructions

Tech Sahayak aims to reduce this difficulty by providing simple and accessible guidance.

## Key Features

* 🗣️ Voice-friendly interaction
* 🌐 English and Tamil language support
* 📱 Android and iPhone device guidance
* 👆 Simple step-by-step instructions
* 🚨 Scam-awareness guidance
* 💡 Easy-to-understand technology assistance

## Project Goal

The goal is to make everyday technology easier to understand and use, especially for people who are less comfortable with digital devices.

## Project Better Tomorrow

Tech Sahayak is being developed as part of the **Project Better Tomorrow** Design Thinking and AI project.

The project follows the Design Thinking approach:

**Empathize → Define → Ideate → Prototype → Test → Improve**

The current stage focuses on developing and refining the prototype and collecting user feedback.

## Technology

The prototype was developed using **Google AI Studio** with AI-assisted development and is maintained using **GitHub**.

## Current Status
